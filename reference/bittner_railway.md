# Bittner Creek railway

Railway track segments that touch the Bittner Creek watershed's bounding
box widened by 5 km, kept whole rather than clipped, so some run past
it.

## Usage

``` r
bittner_railway
```

## Format

An `sf` data frame with columns:

- track_classification:

  Railway track classification

- geom:

  Linestring geometry (WGS 84)

## Source

BC GBA Railway Tracks via newgraph database
